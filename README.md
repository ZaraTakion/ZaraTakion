## Projetos em destaque

### UPA — Upgrade Portal Aluno

Sistema acadêmico desenvolvido como projeto de faculdade para modernizar a experiência de alunos e professores em um portal educacional.

O projeto trabalha conceitos de aplicação web completa, incluindo interface, autenticação, consumo de API, organização de telas e estrutura Back-End.

Tecnologias principais:

* React
* Vite
* Django
* JWT
* SQLite

---

### Análise de Vendas de Loja Fictícia

Projeto de Ciência de Dados utilizando Python e pandas para analisar vendas, faturamento, produtos mais vendidos e padrões comerciais.

O objetivo é transformar dados brutos em informações úteis para tomada de decisão.

Tecnologias principais:

* Python
* pandas
* Jupyter Notebook
* matplotlib

---

### API REST com Django

Projeto Back-End focado na criação de uma API REST com autenticação, banco de dados e organização de regras de negócio.

O objetivo é demonstrar estruturação de aplicações Back-End com Django e boas práticas para projetos web.

Tecnologias principais:

* Python
* Django
* Django REST Framework
* JWT
* PostgreSQL
